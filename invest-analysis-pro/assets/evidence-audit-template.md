# Evidence Audit Appendix Template

```markdown
## Evidence Audit Appendix

- status: ok|partial|failed
- requested modules: [...]
- succeeded modules: [...]
- failed modules: [...]
- source_chain: [...]
- errors: [...]
- warnings: [...]
- confidence impact: <short explanation>
```

Rules:
- This appendix is mandatory for every compliant `quick`, `standard`, `full`, and `specialist` output.
- Do not compress away failed modules, warnings, or source-chain disclosures.
- If confidence is downgraded, say why.
