# 多参考图融合编辑模板

本文件用于基于多张参考图进行融合编辑：把一张图的背景、光线、构图融合到另一张图的主体上，生成自然的一体化画面。不是简单的抠图换背景，而是要求光线、色调、透视、景深全部统一。

代表案例：

- 把 A 图的背景换到 B 图主体上，同时调整光线和构图使其自然融合
- 把产品从一个场景迁移到另一个场景，光影一致
- 把人物从室内场景融合到户外场景

## 适用范围

- 场景迁移 / 背景融合
- 产品场景化重拍
- 人物合成到新环境
- 多素材拼合成一张自然画面

## 何时使用

- 用户说"参考这张图的背景放到那张图上"
- 用户给了 2+ 张参考图要求融合
- 用户说"把这个人/产品放到 XX 场景里，要自然"
- 用户强调"光线要统一""不要像 P 的"

不要使用：

- 用户只要简单换背景（用 `background-replacement.md`）
- 用户只要局部替换物体（用 `local-object-replacement.md`）
- 用户只要去背景做透明底（用 `object-removal.md`）

## 缺失信息优先提问顺序

1. 主体来源图（哪张图的主体要保留）
2. 背景/场景来源图（哪张图的背景/环境要参考）
3. 融合重点（光线统一 / 色调匹配 / 透视一致 / 景深连贯）
4. 输出比例
5. 是否需要保持原图主体的服装/姿态/表情不变

## 主模板：双参考图背景融合

📖 描述

将一张图的主体与另一张图的背景融合成一张自然画面。模型需要同时分析两张参考图的光线、色调、透视和景深，输出一张看起来像"原生拍摄"的结果。

📝 提示词

```text
请将附图 1 中的主体（{argument name="subject description" default="人物/产品"}）自然融合到附图 2 的背景环境中。

融合要求：
- 光线方向和色温必须与背景图一致
- 主体的阴影、反射、环境光要匹配新场景
- 透视和镜头焦段要看起来像同一张照片拍的
- 景深和虚化程度要连贯
- 色调和对比度要统一，不能有一部分偏暖一部分偏冷

不要做成"抠图贴上去"的效果，要像在同一场景一次拍成的。
```

### 参数策略

- 必问：主体来源图、背景来源图
- 可默认：光线匹配优先级 > 色调 > 透视
- 可随机：是否保留原图的部分前景元素

### 自动补全策略

当用户给了两张图但没说清楚哪张是主体、哪张是背景时：

- 优先识别"有明确主体（人物/产品）"的图作为主体来源
- 优先识别"有完整场景/环境"的图作为背景来源
- 如果判断不清，问用户

## 变体 1：产品场景迁移

📝 提示词

```text
请将附图 1 中的产品自然放置到附图 2 的场景中。

要求：
- 产品在新场景中的光影方向、色温、反射必须匹配
- 产品在画面中的比例和透视要合理（不能太大或太小）
- 场景中如果有平面（桌面、地面），产品要"放"在上面而不是"浮"在上面
- 背景虚化程度要与产品的焦平面一致

{argument name="additional instruction" default="保持产品标签和细节清晰可读"}
```

## 变体 2：人物环境合成

📝 提示词

```text
请将附图 1 中的人物自然融入附图 2 的环境。

要求：
- 人物的肤色和光线要受新环境光影响（如室内人到户外，肤色要变户外光感）
- 人物的阴影要投射在新环境的地面上
- 人物与环境之间的遮挡关系要合理（如站在树后应该被遮挡）
- 整体色调要像在同一场景用同一台相机拍的
- 如有前景元素（如栏杆、植物），人物应该与之产生合理的空间关系

{argument name="additional instruction" default=""}
```

## 避免事项

- 不要只调色调不调光线方向，光线方向不对立刻穿帮
- 不要忽略主体和背景之间的影子关系
- 不要把主体缩放到与背景透视不匹配的大小
- 不要忽略环境色对主体的影响（如绿色草地会反射绿光到人物腿部）
- 不要输出明显的抠图边缘或羽化痕迹
- 不要在融合后丢失主体的细节（如发丝、透明物体）

## Text QA Inspection Zones

- 主体上的文字（如产品标签、衣服品牌）：融合后必须仍然清晰可读
- 背景中的文字（如招牌、标牌）：不能因融合操作而变形或丢失
