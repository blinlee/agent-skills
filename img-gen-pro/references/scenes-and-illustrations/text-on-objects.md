# 物体表面文字渲染模板

本文件用于在非常规物理载体上渲染文字——香蕉上的经文、石头上的书法、树叶上的诗句、贝壳上的名字。核心挑战是让文字看起来是"真实地存在于物体表面"的，而不是 PS 贴上去的。

代表案例：

- 香蕉上的般若心经（极细毛笔字在弯曲黄色表面上）
- 石头上的篆刻
- 树叶上的手写诗
- 面包上的果酱字
- 咖啡拉花上的文字

## 适用范围

- 创意产品图 / 礼品定制概念图
- 艺术创作 / 概念设计
- 社媒传播的视觉实验
- 文化创意产品视觉

## 何时使用

- 用户说"在 XX 上写/刻/画 XX"
- 用户要的是文字与物理材质融为一体的视觉
- 用户关注的是"载体 + 文字 + 材质"的组合效果

不要使用：

- 用户要的是字体设计 / 排版（用 `typography-and-text-layout/` 目录下的模板）
- 用户要的是产品标签/贴纸上的文字（用 `product-visuals/` 目录下的模板）
- 用户要的是 UI 界面上的文字（用 `ui-mockups/` 目录下的模板）
- 用户要的是工作台/屏幕真实感（应走独立的 UI / workspace screen 模板，而不是本模板）

## 缺失信息优先提问顺序

1. 载体是什么（水果/石头/纸张/食物/其他材质）
2. 文字内容（经文/诗词/名字/标语）
3. 文字风格（毛笔/钢笔/篆刻/印刷/手写）
4. 文字与载体的关系（刻/写/印/烧/浮雕/自然形成）
5. 拍摄角度和光线

## 主模板：物体表面文字

📖 描述

在指定物体的表面渲染指定文字，文字必须看起来是物理地存在于物体表面的，要考虑材质的弯曲、纹理、反光对文字的影响。

📝 提示词

```text
在{argument name="object" default="香蕉"}表面写上{argument name="text content" default="般若心经"}，让文字真实贴合该物体的弯曲、纹理、反光与材质特性。
```

### 参数策略

- 必问：物体、文字内容
- 可默认：文字风格（根据物体自动推断，如香蕉→毛笔字，石头→篆刻）
- 可随机：拍摄角度、光线方向、背景

### 自动补全策略

当用户只给出"XX 上的 XX"时：

- 根据物体材质自动推断最合理的文字风格
- 香蕉、面包等有机物 → 毛笔/手写
- 石头、金属等硬物 → 篆刻/蚀刻
- 纸张、布料 → 印刷/手写
- 液体表面 → 咖啡拉花/书法
- 自动补全"实物摄影"风格

## 变体 1：书法载体创意

📝 提示词

```text
用普通人的笔迹在{argument name="surface" default="一片秋天的落叶"}上写{argument name="text content" default="人生若只如初见"}。

文字要看起来是用{argument name="writing tool" default="极细毛笔"}写上去的，笔触要与叶片的脉络自然融合。
光线从侧面打来，在文字笔画上产生微妙的阴影。
背景虚化，只有叶子和{argument name="background" default="秋天的木桌"}。
```

## 避免事项

- 不要让文字看起来是后期贴上去的——必须考虑物体表面对文字的影响（弯曲、纹理、反光）
- 不要在光滑表面上生成有笔触质感的文字（矛盾）
- 不要忽略物体材质对"墨迹"的吸收效果（如木头会吸墨渗开，金属不会）
- 不要把文字放得太大或太小——要符合该物体上手写/雕刻的实际比例
- 不要让背景分散对"物体+文字"组合的注意力
- 不要在物体表面生成过于完美的文字——手写应该有自然的不规则感

## Text QA Inspection Zones

- 物体表面的文字：必须可辨认，但不要求完美工整（手写/雕刻本就不完美）
- 如果文字是中文/日文：笔画结构必须正确，不能是乱造的字形
