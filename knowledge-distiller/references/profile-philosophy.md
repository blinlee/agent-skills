# Philosophy Profile

## Goal

Extract transferable judgment: worldview, principles, mechanisms, boundaries, taboos, tensions, and cognitive anchors.

## Inputs

- layered concept table
- relation notes
- conflict notes
- evidence snippets

## Required Sections

```markdown
# [Corpus Name] Philosophy Distillation

## 1. Core Anchors
## 2. Principles
## 3. Mechanism Models
## 4. Boundaries and Failure Conditions
## 5. Taboos and Anti-Patterns
## 6. Tensions and Contradictions
## 7. Evidence Appendix
## 8. Compression / Fidelity Notes
```

## Anchor Format

```markdown
### [Anchor Name]
**Anchor:** [one-line handle]
**Principle:** [transferable judgment]
**Mechanism:** [why it works]
**Boundary:** [where it fails]
**Evidence:** S001, S014
**Confidence:** verbatim / artifact / inference
```

## Rules

- Build anchors from principles and mechanisms, not from vibes.
- Keep concrete examples near abstract claims.
- Preserve contradictions. A philosophy with no tensions is usually over-cleaned.
- When a principle is domain-specific, say so. Do not over-generalize.

## Trader Rendering

For trader courseware, render:

- Layer 5: trading/investment heart method
- Layer 4: investment principle
- Layer 3: market mechanism
- Layer 2: strategy pattern
- Layer 1: tactic or observation

Do not turn a tactic into a principle unless evidence shows it transfers across contexts.
