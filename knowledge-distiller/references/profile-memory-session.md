# Memory / Session Profile

## Goal

Distill chats, work logs, reports, retrospectives, or session notes into durable knowledge and follow-up leads.

## Required Sections

```markdown
# [Corpus Name] Memory / Session Distillation

## 1. Durable Lessons
## 2. Decisions and Rationale
## 3. Open Threads
## 4. Changed Beliefs or Superseded Assumptions
## 5. Follow-Up Leads
## 6. Evidence Appendix
```

## Rules

- Preserve provenance for every lesson or decision.
- Track belief evolution: old view, new view, reason for change, source.
- Mark unresolved items as open threads, not conclusions.
- Do not turn a one-off incident into a universal rule without evidence.
- Keep action items separate from knowledge.

## Belief Evolution Format

```markdown
| Topic | Prior View | Updated View | Treatment | Reason | Evidence |
|---|---|---|---|---|---|
| ... | ... | ... | supersedes / refines / coexists | ... | S001 |
```

## Follow-Up Lead Format

```markdown
| Lead | Why It Matters | Next Step | Evidence |
|---|---|---|---|
```
