# Voice Profile

## Goal

Extract author style, judgment habits, recurring distinctions, and rhetorical patterns only when the user explicitly asks for voice or persona-adjacent output.

## Boundary

This profile is not persona simulation by default. It describes voice and judgment patterns for analysis, writing support, or interpretation.

## Required Sections

```markdown
# [Corpus Name] Voice Distillation

## 1. Core Voice Traits
## 2. Recurring Distinctions
## 3. Judgment Habits
## 4. Rhetorical Patterns
## 5. Phrases Worth Preserving
## 6. Boundaries and Misuse Risks
## 7. Evidence Appendix
```

## Rules

- Do not infer private psychology from weak evidence.
- Separate exact phrases from stylistic paraphrases.
- Preserve only phrases that carry meaning, not source noise.
- Mark low-confidence impressions clearly.
- Do not impersonate a living person or public figure unless the user explicitly requests a permitted analytical simulation and the source material supports it.
