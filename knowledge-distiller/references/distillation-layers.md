# Distillation Layers

Use these layers internally, then render them in the user's domain language.

| Layer | Name | Meaning |
|---|---|---|
| 5 | Anchor | Memorable cognitive handle or heart method |
| 4 | Principle | Transferable judgment, doctrine, or decision rule |
| 3 | Mechanism | Why the principle or strategy works |
| 2 | Pattern / Strategy | Reusable method, play, workflow, or tactic family |
| 1 | Observation / Tactic | Concrete example, operational move, case, quote, or local rule |
| 0 | Evidence | Source text, position, context, and confidence |

## Cross-Domain Rendering

Trader materials:

- Layer 5: cognitive anchor
- Layer 4: investment/trading principle
- Layer 3: market or behavioral mechanism
- Layer 2: strategy pattern
- Layer 1: tactic or observation

Product materials:

- Layer 5: product maxim
- Layer 4: product principle
- Layer 3: user, market, or organizational mechanism
- Layer 2: design/process pattern
- Layer 1: example, decision, or feature observation

Project materials:

- Layer 5: operating maxim
- Layer 4: management principle
- Layer 3: coordination mechanism
- Layer 2: workflow
- Layer 1: meeting/task incident

## Classification Rules

- A concept may occupy multiple layers if the source supports both concrete and abstract forms.
- Do not promote a tactic to a principle unless multiple sources or strong reasoning support transferability.
- Do not create anchors until the supporting principle and mechanism are clear.
- Keep weak anchors as candidates, not final doctrine.
