# Agent Skill

This repository contains standalone agent-skill projects:

- [`img-gen-pro/`](./img-gen-pro/) — template-driven GPT Image prompt and image-generation workflow skill.
- [`LLM-WIKI/`](./LLM-WIKI/) — CLI-first markdown knowledge-base compiler for human-governed LLM wikis.
- [`invest-analysis-pro/`](./invest-analysis-pro/) — evidence-first investment research skill for Agent-led stock analysis workflows.

Each project keeps its own README, license, package metadata, scripts, and operational boundary.
